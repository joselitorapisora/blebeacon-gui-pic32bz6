# PIC32BZ6 BLE Beacon User Data

#### Description:

- Based on official PIC32BZ6 demo applications (starting projects).
- Demonstrates connectionless sending of user data via BLE legacy advertising packets (beacon).
- Data includes node ID, temperature sensor value, counter, and a switch.
- Central device displays the received data onto an ST7789-based SPI display.
- GFX component from Legato library.


#### Hardware:

- (2) PIC32-BZ6 Curiosity Board
- Generic ST7789 320x240 display module
